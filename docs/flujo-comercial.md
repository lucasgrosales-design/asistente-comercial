# Flujo comercial

1. Entra un contacto.
2. Se identifica al contacto.
3. La IA extrae información básica.
4. Se crea/actualiza la oportunidad.
5. Se asigna al vendedor.
6. El vendedor realiza la conversación comercial.
7. La interacción se registra.
8. La IA actualiza el resumen breve.
9. Se define o sugiere el próximo paso.
10. El siguiente vendedor o responsable puede entender la situación sin reconstruir toda la conversación.

## Estados MVP
- Nuevo
- En conversación
- Seguimiento
- Venta
- Perdido
- Inactivo

Seguimiento vencido es una alerta, no un estado.
